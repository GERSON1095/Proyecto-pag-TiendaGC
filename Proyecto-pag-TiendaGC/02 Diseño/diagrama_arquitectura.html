GC Tienda – Diagrama de arquitectura

Frontend (Presentación)

HTML · Bootstrap 5 · JavaScript (i18n, chatbot)
Vistas PHP: catálogo, login, registro, carrito, checkout, pedidos, panel admin

↓ HTTP (GET / POST) · Sesión PHP

Backend / Lógica de negocio

PHP 8 + PDO
Auth y roles · CRUD productos · Inventario · Pedidos (transacciones) · Cifrado AES-256

↓ PDO / SQL

Base de datos

MySQL · Base gc_tienda
usuarios · categorias · productos · pedidos · detalle_pedido · atenciones_chatbot

Esquema del enunciado: Frontend → Backend / API → Base de datos

En este proyecto el “Backend / API” es la capa PHP de lógica de negocio (sin API REST separada). Se justifica por continuidad del proyecto existente y por facilitar la demostración de la relación interfaz ↔ lógica ↔ datos.
